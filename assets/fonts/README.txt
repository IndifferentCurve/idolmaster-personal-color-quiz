Quiz Sans

Self-hosted variable-weight subsets of Noto Sans KR (Latin, Hangul) and
Noto Sans JP (Japanese). The CSS family name is Quiz Sans. Weight axes
and the fonts' original license metadata are preserved.

Sources:
https://fonts.google.com/noto/specimen/Noto+Sans+KR
https://fonts.google.com/noto/specimen/Noto+Sans+JP

License: SIL Open Font License 1.1. See the two accompanying OFL files.
Subsets cover the UI and idol names present in index.html, root JavaScript
and data/series. Other characters fall back to the user's installed fonts.
Rebuild after adding new names or translations:
reference_assets/font-subsets/build.py
